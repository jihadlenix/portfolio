The Mission

Manual work is a bug. I ship the patch.

Every organisation runs on processes a person has to remember to do. Intake handled by hand. Budgets recalculated in a spreadsheet. Data corrected by whoever noticed first. I replace those with systems that run on a trigger, with approval gates, audit logs, and rollback, so the automation is something you can actually trust in production.

Pillar 01

AI Agents & Agentic Systems

Agents that do the work, then show you what they did.

I build AI agents that do real work under real guardrails. The API Integration Agent reads API documentation, extracts endpoints, auth and schemas, generates working integration code, then runs a generate, sandbox-test, self-correct loop that feeds runtime errors back to the model, so faulty output never ships. The Data Quality & Repair Assistant runs SQL checks, diagnoses issues and proposes fixes in plain English with change previews. Both keep every change reviewable and reversible through approval controls, audit logs and rollback.

Pillar 02

Workflow Automation & Integrations

Connecting systems that were never meant to talk.

Most manual work survives because two systems do not speak to each other. I close that gap with n8n, REST APIs and webhooks. An AI lead qualification workflow receives inbound leads by webhook, has Claude classify each one as Hot, Warm or Cold with written reasoning, and stores the reasoning alongside the score, so sales can see why a lead was ranked before they call. These run as concurrent engagements, from requirements through testing, documentation and rollout.
